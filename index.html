东方财富妙想 Skills · API Key

妙想 Key 由东方财富「妙想 Skills 广场」免费领取（mkt_ 开头），每日限量免费额度；仅保存在本机浏览器，不上传云端。未配置时妙想类技能显示「待配置凭据」，问答自动只用免费公开数据源（功能略少，仍可用）。

免费额度怎么领？（不用买妙想 token）
1. 打开妙想 Skills 广场：marketing.dfcfs.com/views/finskillshub；
2. 点「API KEY 领取」，拿到一串 mkt_ 开头的 KEY；
3. 回到这里粘贴 → 点「测试连接」→「保存」。
额度按自然日刷新（妙想 App「API Key 管理 → 消耗」可看各技能当日用了几次）。免费额度约 2 秒才能问一次，问太快会自动排队重试。
已安装技能 停用即真正关闭该能力；问答只调用已启用的技能；对话里也可以直接说「安装/卸载/停用 某技能」
📚 浏览可安装的技能（卸载的会出现在这里，可随时装回）
📦 安装 SKILL.md 技能包（整包安装，如 a-stock-data 全部 54 端点）

整包安装 = 把整个技能（内嵌 Python）装到你的服务器上执行。前提：已部署自托管后端（deploy/），并安装 Python 与依赖（pip install requests pandas）。 WorkBuddy 云端托管没有 Python 运行时，只能用内置的 a-stock-data 移植技能（7 个常用端点）。混合模式：界面与数据继续用 WorkBuddy 托管，技能包跑在你自己的服务器上（运行时地址需 HTTPS）。

➕ 新建自定义技能（接任意东财公开报表，免 Key）

填一张表就能把「东财数据中心」的任意公开报表变成问答技能：给几个触发关键词（对话里出现就自动调用）、 报表名（如 RPT_LIFT_STAGE）和想看的列。取数走免费公开接口，与内置技能同一套审计日志。 报表名与字段可在 东财数据中心 各列表页的接口里查到，开源项目 a-stock-data 的 SKILL.md 里有现成清单。

📋 各技能的数据来源一览（问答里的数字从哪来）

问答时会话里每张数据表的标题下都标了「数据来源」，工具便签的能力标签也会标注来源；取数原则：免费优先 —— 免费公开数据能取到的绝不动用妙想额度，妙想只补「资金流向 / 北向 / 两融 / 机构调研」这类免费表没有的口径。
